## 结论

重构 table/ex 纯逻辑（如 spans.js）前，先在 demo 自检中加临时探针，采集可序列化行为快照为「冻结基线」（如 9 条警告消息原文序列、regions 构建序 `["2-3x5-7",...]`），重构后要求探针输出与基线**逐字一致**且自检全绿；交付前删除探针并复验全绿。双安全网（探针比对 + 自检用例）可拦截中间轮缺陷。
