# 级联延时收起：hide 不可向上清祖先计时器

## 结论

多层级联弹层（每层独立 hideTimer，离开时整链同时臂定同延时）中，`hide()` 只能清**自身**计时器（直接 `clearTimeout`），不可复用「向上递归清全链」的 `clearHideTimer()`；向上清仅属于两个场景：面板 `mouseenter` 保活、`delayHide` 重臂前清理。

## 原因

链收起时各层计时器几乎同时臂定、按臂定顺序先后触发（最深层先）。先触发层的 `hide()` 若向上清，会取消祖先**尚未触发**的计时器，祖先面板滞留成孤儿（实测：side-menu 三层链离开后 L1/L2 滞留不关，L3 单独收起）。

## 注意

- 「进入面板清祖先」与「收起时清祖先」语义相反：前者保活整链，后者拆掉整链的收起。
- 单层弹层（无祖先）两种写法等价，bug 只在引入级联后暴露。
