## 偏离

1. **设计内两处口径不一致，取判据口径（非行为偏离）**：改动清单 layout.js 行的 `typeNameOf` 内联示意 `typeof col.type === 'string' ? (col.type || 'text') : '_fallback'` 会把**无 type 列**归入 `_fallback`（80/40）；而 A3.2 表、G2 判据与 03-review-5 问题 1 均明确「无 type 列回退 text（160/80，与 resolveColumnType(undefined) 回退 TextColumn 一致）」。按 A3.2/G2 判据实施：`typeof type === 'string' ? (type || 'text') : (type == null ? 'text' : '_fallback')`。首版按示意实现即被自检「无 type 160」断言拦截，已修正。
2. **约束 4 的应用范围**：派发口径「溢出/dots 字符一律 '...'（三个半角点）」——除 maxLines 末行收缩与 maxItems dots 外，将 painter.js 表头 caption 单行省略与 cell-painters 单行超宽省略的既有 `'…'`（U+2026）一并统一为 `'...'`。设计 A3.5 原文该两处保留 '…'（CSS ellipsis 同款视觉），按派发「一律」与 decisions「溢出字符按 '...'（用户确认）」执行，如需回退仅 2 处常量。
3. **self-checks 期望修正 4 处**（测试侧，非实现）：① canvas `fillStyle` 赋值后回读序列化为 `#rrggbb`，期望值经 `cssColorOf` 归一；② `fakeMeasure` 实际 9px/字符（CJK 7px + 全字长 2px 记账），首行断言按 16 字符修正；③ LinkColumn 现状 `itemClass = ['mu-link', _class]` 含 null 占位位（DOM 既有行为，设计「包裹行为不变」），断言改为「首元素 mu-link 且 join 后不含 mu-link--」；④ 数字条目 `item.text` 保持原始 number（render 不做 String 化），断言按 number 修正。
4. **itemHits 矩形口径**（设计未规定的实施细节）：link 竖排条目命中矩形 = 文本 x + lineHeight 条带（18px 高）；button/横向 tag = 条目宽 × 格高；dots 条目同规格回报。G3 `resolveItemClick`（hit.x/hit.y 反查）按此消费。
