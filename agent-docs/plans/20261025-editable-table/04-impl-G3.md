## 偏离

1. **设计 A5.1/改动清单 editor 行「`<component :is="'textarea'">` + v-model」机制不可行，改模板分支渲染真实 `<textarea class="mu-input" v-model>`**：`<component :is>` 上的 v-model 经 Vue 编译为 `modelValue` prop，动态组件解析为原生 textarea 后落入 `modelvalue` attribute（页面实证：`<textarea modelvalue="多行备注第一行…">`、`el.value` 恒空），不产生 vModelText 语义——设计的「vModelText 同款语义」目标不变，机制按语义要求改为模板 `v-if` 分支（textarea 走原生元素 + class="mu-input"，与 G2 scss `__editor > textarea.mu-input` 约定一致）；`EDITOR_COMPONENTS.textarea = 'textarea'` 字符串与 resolveEditorComponent 契约保持不变（类型解析/自检身份断言不受影响）。
2. **设计缺口补齐：interactions.hitTest 增可选 `rowGeometry` 参数**：A2.2 要求「painter/layout/interactions/editor 全部经几何接口取行坐标」，但 interactions.js 改动行未列该入参——变高模式下 hitTest 的 rowAt 走 uniform 算式会命中错行。增可选参数透传 G2 layout.rowAt（未传行为与现状恒等），非白名单外改动。
3. **模式判定实施修正（实现 bug，验证拦截后修正）**：初版 relayoutAndRedraw 仅在估高返回 hasArrayValues 时升级 variable，候选列（maxLines>1 / multiline）只估高不升级——与 A2.2「列输入（maxLines>1/multiline 配置存在）或数据输入（数组值）→ variable」不符，树场景验证发现后修正为候选即升级；同时引入扫描输入变更标记（records/columns 引用未变的 uniform relayout 跳过全量扫描，防容器 resize 高频重扫——设计「估高在 records/columns 准备期运行」语义保持）。
4. **编辑浮层 focus 滚动漂移修复（现状缺陷，白名单内）**：`focus()` 会把最近可滚动祖先滚出溢出量——`__overlay` 为 `overflow: hidden` 亦可被程序化滚动，宽表格下浮层超出视口右缘时 overlay.scrollLeft 被滚至 83（实测），浮层相对画布漂移 83px。`focusEditor` 聚焦后复位 overlay.scrollLeft/Top = 0。治本方案为 scss `overflow: hidden → clip`（clip 不可滚动），scss 不在本步白名单，留 S1/后续（遗留 2）。
5. **resolveTreeToggle 增 `recordKey` 入参**：设计签名 `{ hit, columns, flatInfo }` 返回 `{ row, key }`，key 需组件壳按树 key 字段解析传入（纯函数无取数上下文），壳侧经 resolveRecordKey（树模式树 key 字段）提供。
6. **无 type 列编辑器判定回退 text**：设计 A5.5 字面「text/link 列」判定不含无 type 列，而 A3.5 列分类明确无 type = TextColumn（文本呈现列）——demo 数组值列（无 type）初测开成 input，按 A3.5 口径修正为 `type == null → text` 参与形态判定。
7. **cell-item-click 的 canvas 侧 dots payload**：canvas `maxItems` 截断产生的 dots（DOM render 未配 option.max 时不产 dots 条目）payload 按 A1 口径统一 `'...'`（`render 条目数 > _maxItems && index === _maxItems − 1` 判定）；DOM render 自产 dots（item.text === '...'）同值。e2e 验证 `link: "..."` + recordIndex。
8. **「前轮夹具」实际不存在于工作区**（check disabled id%10===0、price clearable、「最近提交」typeof、`__tableExEditable` 等仅见设计文本），按改动清单在本步随 G3 夹具一并落地——非回退，首次实现。
